导出 Firefox 续期凭据

此页面完全在本机处理文件，不发送网络请求。它只从 Firefox 的 signedInUser.json 中导出续期需要的邮箱、uid 和 session token。

  1. 先在当前电脑的 Firefox 设置中登录 Firefox Account，并在浏览器里完成邮箱码、CAPTCHA 或两步验证。
  2. 打开 IP Protection 面板完成首次启用，并等待 Firefox 完成设备注册。
  3. 打开 about:profiles，在已登录的配置下打开“根目录”。
  4. 回到本页，选择根目录中的 signedInUser.json。

凭据包等同于登录会话。不要通过聊天、邮件或公开网盘传输；导入 VPS 后立即删除传输副本。关闭 Firefox 不会使会话失效，但在 Firefox 中退出账号或从账号设备列表撤销该会话会使 VPS 无法续期。
